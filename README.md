# GlassWall

**GlassWall — Secure Local File Transfer Without the Cloud**

GlassWall is a cross-platform file-sharing application built with Flutter that enables fast, secure, and private file transfers between devices on the same local network.

Inspired by LocalSend, GlassWall focuses on simplicity, privacy, and performance. Files are transferred directly between devices without relying on cloud services, external servers, or internet connectivity.

---

## Features

* 📁 Transfer files and folders instantly
* 🔒 Secure peer-to-peer communication
* ⚡ Fast local network transfers
* 🌐 No internet connection required
* 🖥️ Cross-platform support
* 🎨 Modern Flutter-based user interface
* 🚫 No cloud storage involved
* 🔓 Open-source and community-driven

## How It Works

GlassWall uses a peer-to-peer architecture for local file transfers.

```text
Sender Device
       │
       ▼
 Local Network
       │
       ▼
Receiver Device
```

Files move directly between devices without passing through any external servers.

## Why GlassWall?

GlassWall is designed for users who want a simple and secure way to transfer files between devices without uploading data to external services.

Whether you're sharing documents, images, videos, or project files, GlassWall keeps your data on your network and under your control.
